# SWC Grid Slope（坵塊法坡度分析）QGIS 外掛

依《水土保持技術規範》坵塊法計算坡度、分級與坡向，並自動產製坵塊圖、出圖版面與 GeoPackage 專案。

> 《水土保持技術規範》主管機關：**農業部農村發展及水土保持署**（ARDSWC：Agency of Rural Development and Soil and Water Conservation, MOA）。本套件為獨立開發之工具，非該署官方產品；計算成果仍應由專業技師依規範檢核。

## 規範依據
| 條文 | 內容 | 外掛實作 |
|---|---|---|
| 第 23 條 | 坡度係一坵塊土地之平均傾斜比；一～七級坡 | `grade`、`grade_name` 欄位、著色與統計 |
| 第 25 條 | 坵塊法：每 10 m 或 25 m 畫一方格；各邊與等高線交點數註於邊上，四邊總和註於中央；S = nπΔh/(8L)×100 | `n_top/n_right/n_bottom/n_left`、`n`、`S_pct`、`theta_deg` |
| 第 26 條 | 坡向：方格坵塊內垂直等高線向下坡之方向 | `aspect_deg`（北=0° 順時針）、`aspect`（八方位）、坡向圖（點圖層，空心箭頭指向下坡） |

坡度分級：一級 S≦5%、二級 5<S≦15%、三級 15<S≦30%、四級 30<S≦40%、五級 40<S≦55%、六級 55<S≦100%、七級 S>100%。
π 預設 3.14（與規範表列一致，N=12、Δh=1、L=25 → 18.84%），可改用 math.pi。

## 操作流程（右側面板）
1. **地形資料**：選「等高線」（指定圖層與高程欄位，可自動偵測 Δh）或「DEM」（以 Δh 自動產生等高線）。
2. **坵塊設定**：L = 10 或 25 m；**計畫範圍為必選**（未選擇或圖層沒有圖徵時，繪製、編輯與計算皆會提醒無法執行；面積統計以範圍內面積計）。
3. **方格範圍**：
   - 「繪製矩形」：在地圖上拖曳，產生記憶體暫存圖層「坵塊方格範圍（編輯中）」並即時預覽方格。
   - 「平移/旋轉/縮放」：拖曳內部平移、拖曳角點/邊中點改尺寸（對側固定）、拖曳橘色圓點旋轉（Shift 以 5° 為單位），方向鍵微移（Shift = L）。
   - 「依計畫範圍」：以計畫範圍最小外接旋轉矩形建立。
   - 亦可直接輸入中心、寬、高、旋轉角；勾選「整數倍」時自左上角起算填滿。
   - **矩形範圍須包含計畫範圍**：每次繪製、平移、旋轉、縮放或輸入數值後自動檢查，未包含時以整格自動擴充（方格線位置不變）並提醒。
   - 按下計算時再檢查一次：矩形方格之範圍若未完全包含計畫範圍（例如之後修改了計畫範圍圖層），即提醒無法執行，不會自動擴充。
   - 預覽只顯示與計畫範圍有交集（Overlay）之坵塊，並顯示交集格數。
4. **計算與展示**：按「產出坵塊並計算坡度及坡向」，**僅針對與計畫範圍有交集之坵塊**計算交點數、坡度、分級與坡向；標註可選「文字式（分級/N/S）」或「圖式（大字級數＋圈號交點數＋(S%)）」。成果放在圖層群組「坵塊法坡度坡向分析」下：
   - 子群組「坡度圖」：等高線交點（預設不顯示）、坵塊邊界（各邊交點數）、坵塊方格範圍、坵塊坡度分析。
   - 子群組「坡向圖」（預設關閉顯示）：
   - 「坵塊坡向（箭頭）」點圖層：每格中心一個空心方塊箭頭，指向下坡之八方位（`aspect_dir`）。
   - 「坵塊坡向分區」：坵塊格線。
5. **出圖版面**：「建立版面」同時建立（覆寫）「坵塊法坡度分析圖」與「坵塊法坡向分析圖」兩個版面（A3/A4/A1 橫式），圖面框住實際產出的坵塊，比例尺刻度自動選取；坵塊邊界交點數字依版面比例尺放大，出圖約 2.6 mm 字高。等高線交點是否出現在版面，依圖層面板勾選而定（預設不顯示）。坡向圖版面含指北針、比例尺、圖例（計畫範圍、坡向）、坡向面積統計表、說明與「專業技師簽證」欄；「匯出 PDF/PNG」選擇資料夾後一次輸出 `QGIS專案名稱_坡度圖` 與 `QGIS專案名稱_坡向圖`（格式於「匯出格式」選擇；專案未存檔時名稱為「坵塊法坡度坡向分析」）。
6. **儲存成果**：選擇輸出資料夾並輸入專案名稱，資料夾內產生 `專案名稱.qgz` 與 `專案名稱.gpkg`；計算成果、輸入資料（等高線/DEM/計畫範圍）與專案中的記憶體暫存圖層皆寫入 gpkg，圖層樣式一併存入。檔案已存在時會詢問是否覆蓋；若該 gpkg 正被目前專案使用，自動改名為 `專案名稱_2`。寫入全部成功後才切換圖層來源，失敗不會影響目前專案。
   - 單波段 Float64/Int32 網格會轉為 Float32 存入；GeoPackage 無法儲存的多波段影像（超過 4 波段或非 Byte）會列在完成訊息中並保留原檔連結。

另提供 Processing 工具「坵塊法坡度分析」，可批次或於模型建構器使用。

## 注意事項
- 支援 QGIS 3.22 – 4.99（Qt5 與 Qt6），已於 QGIS 3.34 與 4.2.3 實測。
- 專案座標系須為公尺制投影座標（TWD97 / TM2：EPSG:3826、3825）。
- 等高線剛好通過方格節點時，該交點於坵塊總數 n 只計一次。
- 規範第 25 條另規定無實測地形圖者得採等高線法；本外掛僅實作坵塊法。

## 安裝
- 從 [Releases](https://github.com/yoshihuang/swc_grid_slope/releases) 下載 `swc_grid_slope.zip`，於 QGIS「外掛 → 管理並安裝外掛 → 從 ZIP 安裝」。
- 或自行打包：`zip -r swc_grid_slope.zip swc_grid_slope`。
